SPECIAL CASES & GOTCHAS

  1. CoreWeave Non-GAAP Metrics
     - Non-GAAP rows are close to GAAP rows (off by 9)
     - For DCF always use GAAP (rows 44, 59, 99)
     - Non-GAAP = Excl. SBC, Amortization of Intangibles, etc.

  2. TSMC CapEx is in Billions
     - Row 86 value is in "bn" not "mm"
     - Must convert: CapEx(mm) = CapEx(bn) × 1000

  3. Working Capital Not Explicit
     - None of the models break out AR, Inventory, AP detail
     - Recommend using 10-15% of Revenue as NWC approximation
     - Or search for individual balance sheet items (rows 250+)

  4. Period Labels are Formula-Driven
     - Row 5 contains formulas like: =CONCATENATE("FY",RIGHT(C5,4)+1)
     - Use dynamic lookup: read row 5 and search for target period
     - Static mappings provided in guide but verify first

  5. Margin Improvements in Basis Points
     - Rows with "improvement" or "bps" suffix
     - Example: Row 40 = "Y/Y improvement in Gross Margin, bps"
     - Use for scenario analysis: cascade improvements period-over-period
     - Additive: New Margin = Old Margin + (bps improvement / 10000)

  6. Deferred Revenue (ASML Only)
     - Row 66: "Net deferred revenue from fast shipment"
     - Row 67: "Normalized revenue" (adjusted)
     - Use normalized revenue for consistent forecasting
