6. PERIOD LABELS (Row 5)
================================================================================

How to identify columns dynamically:
  1. Read Row 5 for all columns
  2. Search for text patterns:
     - "FY2025", "FY2026", etc. → Annual columns
     - "Q1-26", "Q2-26", etc. → Quarterly columns
     - "2025" or "2026" → Year identifier
  3. Map column letters to period labels
  4. Use in Python with openpyxl: ws.cell(5, col_idx).value


Example mapping function:
  def get_column_for_period(ws, target_period):
      """
      target_period = "FY2025" or "Q1-26"
      returns column letter: "L" or "H"
      """
      for col_idx in range(3, ws.max_column + 1):
          label = ws.cell(5, col_idx).value
          if label and str(target_period) in str(label):
              return get_column_letter(col_idx)
      return None

7. MARGIN IMPROVEMENT DRIVERS (FOR PM AGENT)
================================================================================

Each margin drives as basis points (bps) change from baseline.

Cumulative Effect:
  Margin (%) = Baseline Margin + Y/Y Improvement (bps) / 10000

Example:
  Gross Margin FY2025: 50%
  Y/Y Improvement: 200 bps
  Gross Margin FY2026: 50% + (200 / 10000) = 50% + 0.02 = 50.2%

10. VALIDATION CHECKS
================================================================================

Before using extracted data, validate:

1. Revenue Integrity:
   - Total Revenue (Row 25/7/41) = Sum of segments (if applicable)
   - Growth rates are reasonable (typically -10% to +50% for hardware)

2. Margin Integrity:
   - Gross Margin < 100% and > 0%
   - EBIT Margin < Gross Margin (because of OpEx)
   - Margin % values should be in range [0, 100]

3. D&A Integrity:
   - D&A / Revenue typically 5-15% for capital-intensive hardware
   - D&A should be positive
   - Total D&A = Depreciation + Amortization (if separate rows exist)

4. CapEx Integrity:
   - CapEx / Revenue typically 10-30% for hardware companies
   - CapEx should be positive
   - CapEx in billions should be converted to millions

5. Period Consistency:
   - All columns in Row 4 should have dates
   - All columns in Row 5 should have period labels
   - Period sequence should be chronological
